### Fixed
- Explicit file links keep their source preview even when Git lists the file as changed, and
  browsing changed media keeps its image, video, audio or PDF preview.
- Copying a selection through a chat code block preserves its final newline, and standalone file
  readers receive keyboard focus for scrolling on arrival.
- A model label clipped at a fractional minimum width steps out before it crowds the context ring
  or Send button.
